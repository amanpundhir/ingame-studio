# Security policy

InGame Studio is a hackathon project that runs on synthetic data. If you find a security problem,
please open a private security advisory on the GitHub repository (Security tab, "Report a vulnerability")
instead of a public issue, and include the steps to reproduce it. Never include real credentials in a report.

Do not commit secrets. Keys belong in a git-ignored `.env` file or in your cloud secret store; `.env.example`
shows the variable names only.
